## Code Review Rules

These are this repo's review guidelines (Codex code review reads this section; older Codex docs call it
"Review guidelines"). Report only P0 and P1. Wording, spelling, style, naming and commit messages are
never findings (owner rule, 2026-10-31).

- **P0:** breaks the build or CI on host g++ 13.3 or NDK clang `-Werror`; a crash, hang or leak in
  the game; lets a secret, signing key or token leak; weakens a test.
- **P1:** a wrong physics or gameplay result, a determinism break, a bypass of her force budget, or a
  protected change made outside a protected PR.

### Physics lives in native code
- Native C++17 and Jolt own all physics and game logic; Godot only shows it. Flag forces, velocities,
  contact rules or game decisions written in GDScript.
- She has one force budget (8 kN, 44 kW). Every force on her or from her (grip, push, pull, a held
  load, a contact reaction she drives) is drawn from that budget; a new force path that skips it is
  P1 (example: the P1 on #193). No velocity writes; at most 0.20 m per 1/90 s tick.
- Climbing is general skills only: no per-route, per-deck or per-transition code.

### Determinism
- No unseeded randomness, no wall-clock time in the simulation, no iteration over an unordered
  container (`unordered_map`, `unordered_set`, pointer-keyed maps) that feeds the simulation.
- No float behavior that can differ between host g++ and NDK clang under the CI flags in
  `.github/workflows/wo000-delivery-spine.yml` (fast-math, FMA contraction, `long double`, unordered
  reductions).
- A comparator passed to `sort`, `set` or `map` must be a strict weak ordering (no `<=`, NaN-safe).

### Tests and protected changes
- Tests are never weakened, skipped or deleted. A moved `require`, limit, timeout, tolerance, pin or
  ctest slice is a protected change: a PR from `<agent>/integrate-protected-<job>` holding only that
  change, with a plain before/after. The same holds for world geometry, the save layout, and her
  force, power, mass, leg-travel or launch limits. Dropping a known-defect entry from an `EXPECTED` list
  (`tools/matron_probe/check.py`) that the same PR's fix clears is not a moved check: it rides with that fix
  (the checker fails a cleared entry as XPASS, so a split is red on one side).
- Human sounds (voice, breath, effort, gore foley) are real recordings or generated by
  `src/voice/generate_fall_voice.py`; flag one synthesized in code.

### GDScript / C++ boundary
- Values cross the bridge as bridge types; flag a raw pointer or engine object held across frames.
- No blocking call (file, network, thread join, long native step) on Godot's main thread.
- Every allocated node, resource or native handle is freed (`queue_free`, ownership, RAII).

### Workflows and signing are HIGH risk
A change to `.github/workflows/`, `.github/actions/`, the APK signing steps or `tools/switchboard/` is
reviewed against `SECURITY.md`: `permissions:`, secrets, `pull_request_target`, untrusted input in
`run:`, action pinning, and the keystore.
