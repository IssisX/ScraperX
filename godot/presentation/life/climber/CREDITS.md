# The climber's body: credits

Built by `tools/body/build_climber_body.py` (run it to rebuild it) from
MakeHuman's CC0 1.0 scanned body: a young man of average build, scaled so
his eyes are where the camera is. Every input is pinned by SHA-256 in
`tools/body/sources.json` (MakeHuman,
`github.com/makehumancommunity/makehuman`, commit
`a8bc2d54ff0ac92e78ff71431b1023eda42bf482`). No MakeHuman program code
(AGPL) is used: the formats are read by the build script.

The build also writes `climber_body_rig.gd` and `climber_body_rig.json`
(text, not shipped binary assets).
